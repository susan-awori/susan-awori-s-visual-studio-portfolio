### 1. TradePass – AI Trade Assistant
An intelligent AI assistant built for GOMYCODE's "Come Build with AI" hackathon (Kenya) helping African cross-border traders navigate customs rules, required documentation, and AfCFTA tariff compliance.
- **Category:** Artificial Intelligence & Machine Learning
- **Technologies:** Python, Gradio, Gemini & Groq LLMs, AfCFTA Rules of Origin, Prompt Grounding
- **Key Features:** Conversational document checklist, origin qualification evaluation, hallucination-resistant grounding
